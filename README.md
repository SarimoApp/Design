# ✦ About

Sarimo Design is the dedicated visual repository for:

* UI explorations
* Motion concepts
* Reader layouts
* Navigation systems
* Glass/soft-shadow experiments
* Typography systems
* Animation studies
* Design tokens
* Interface architecture

The goal is to create a reading experience that feels:

* cinematic
* immersive
* futuristic
* minimal
* calm
* responsive

---

# ✦ Design Language

## Core Principles

* Minimal visual clutter
* Smooth motion hierarchy
* Soft-shadow depth system
* Layered transparency
* Cinematic transitions
* Focused reading experience
* High readability
* Floating navigation patterns
